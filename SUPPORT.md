# Support & Getting Help

Welcome! If you have questions, found a bug, or want to request a feature, here's where to go.

## Questions & Discussions

Have a question about using Tikka, deploying contracts, or building with the platform? Head to **GitHub Discussions**.

- **GitHub Discussions**: [tikka-contracts/discussions](https://github.com/stellar/tikka-contracts/discussions)
  - Best for: How-tos, architecture questions, integration advice
  - Tips: Search existing discussions first—your question may already be answered

## Reporting Bugs

Found something broken? Please open a GitHub issue with details.

- **GitHub Issues**: [tikka-contracts/issues](https://github.com/stellar/tikka-contracts/issues)
  - **Use the bug template** to include: what you expected, what happened, and how to reproduce it
  - Include relevant logs, error codes, and contract/environment details
  - Reference [`docs/ERRORS.md`](docs/ERRORS.md) if you hit contract errors

## Requesting Features

Want a new feature or improvement? Open a GitHub issue.

- **GitHub Issues**: [tikka-contracts/issues](https://github.com/stellar/tikka-contracts/issues)
  - **Use the feature request template** to explain the use case and proposed solution
  - Include context on how it would help your work
  - Search open issues first to avoid duplicates

## Choosing the Right Channel

| You want to... | Go here |
|---|---|
| Ask how to do something | [GitHub Discussions](https://github.com/stellar/tikka-contracts/discussions) |
| Report a bug or crash | [GitHub Issues](https://github.com/stellar/tikka-contracts/issues) with bug template |
| Suggest an improvement or new feature | [GitHub Issues](https://github.com/stellar/tikka-contracts/issues) with feature template |
| Discuss security concerns | See [SECURITY.md](SECURITY.md) (if available) or email security contact |

## Before You Ask

- **Check the docs**: Most questions are answered in [`docs/README.md`](docs/README.md) and [`docs/FAQ.md`](docs/FAQ.md)
- **Search existing issues and discussions**: Your question may already be answered
- **Review [`CONTRIBUTING.md`](CONTRIBUTING.md)**: Covers setup, development, and code submission

## Timing

We aim to respond to issues and discussions during business hours. For security issues, see responsible disclosure guidelines (if available).
